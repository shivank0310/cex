CEX Platform

Frontend placeholder — API gateway routes to backend services.

  • GET /api/v1/market/ticker/BTC/USDT — market data
  • POST /api/v1/orders — place order (off-chain matching)
  • GET /api/v1/ledger/balance/{user}/{asset} — ledger balance
  • POST /api/v1/wallet/address — deposit address
  • GET /gateway/health — gateway health

Order matching runs off-chain in matching-engine. Blockchain is used for deposits and withdrawals only.
